Run your tests against a real IBM Planning Analytics (TM1) server in Docker, with Testcontainers. No IBM software is included: you supply your own licensed TM1 Server for Linux, and tests that need TM1 are skipped without it.

Getting started

  1. Add it to your tests. Gradle:

    testImplementation("io.skipcheck:tm1-testcontainers:{{version}}")

    Maven:

    <dependency>
  <groupId>io.skipcheck</groupId>
  <artifactId>tm1-testcontainers</artifactId>
  <version>{{version}}</version>
  <scope>test</scope>
</dependency>

  2. Tell it where your TM1 is. The quickest way is the folder holding IBM's tm1server-*-linuxi38664h_bundle.tar.gz download, with Docker running:

    TM1_BUNDLE_DIR=~/Downloads ./gradlew test

    {@link io.skipcheck.tm1.testcontainers.Tm1Source} lists the other ways, such as an installed TM1 or a private image, which start in seconds.

  3. Write a test. {@link io.skipcheck.tm1.testcontainers.RequiresTm1 @RequiresTm1} starts a TM1 server for the test run, shares it between test classes, and skips the tests when Docker or TM1 isn't available:

    {@snippet class = examples.HelloTm1TestExamples region = hello-test}

Where next

  • {@link io.skipcheck.tm1.testcontainers.RequiresTm1}: test classes in full, and skipping by TM1 version.
  • {@link io.skipcheck.tm1.testcontainers.Tm1ServerContainer}: a server of your own, with the sample data or your own database.
  • {@link io.skipcheck.tm1.testcontainers.PlanningAnalyticsEnvironment}: several servers, TM1 Web, Workspace and Cognos security together.
  • tm1-client: the client the tests use.
