A reactive Java client for the IBM Planning Analytics (TM1) REST API: every endpoint as a typed service, with a model generated from TM1's own metadata.

Getting started

  1. Have a TM1 server to talk to. To run one on your own computer in Docker, follow Run TM1 on your own computer. It takes about 15 minutes, and you need your own licensed copy of TM1 Server.

  2. Add the client to your build. Gradle:

    implementation("net.ajmyers.tm1:tm1-client:{{version}}")

    Maven:

    <dependency>
  <groupId>net.ajmyers.tm1</groupId>
  <artifactId>tm1-client</artifactId>
  <version>{{version}}</version>
</dependency>

    It needs Java 17 or later.

  3. Say hello. This connects, prints the server's version and lists its cubes:

    {@snippet class = examples.HelloWorld region = hello-world}

Where next

  • {@link net.ajmyers.tm1.client.Tm1Client}: the entry point, with a service for each area of TM1, such as {@link net.ajmyers.tm1.client.service.cube.CubeService cubes} and {@link net.ajmyers.tm1.client.service.data.CellsetService cellsets} for reading data. Each service's page shows how to use it.
  • {@link net.ajmyers.tm1.client.session.Tm1Session}: logging in with CAM, sandboxes, and sending a request no service covers yet.
  • tm1-spring-boot-starter: the client as a Spring Boot bean, configured from properties.
  • tm1-testcontainers: test your code against a real TM1 server in Docker.
