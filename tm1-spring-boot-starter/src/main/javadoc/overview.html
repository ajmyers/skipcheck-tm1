The TM1 client as Spring Boot beans, configured from tm1.* properties.

Getting started

  1. Have a TM1 server to talk to. To run one on your own computer in Docker, follow Run TM1 on your own computer. You need your own licensed copy of TM1 Server.

  2. Add the starter to a Spring Boot 4 application. Gradle:

    implementation("net.ajmyers.tm1:tm1-spring-boot-starter:{{version}}")

    Maven:

    <dependency>
  <groupId>net.ajmyers.tm1</groupId>
  <artifactId>tm1-spring-boot-starter</artifactId>
  <version>{{version}}</version>
</dependency>

  3. Tell it where TM1 is. The starter connects with the tm1 settings in application.yml; these are the defaults of a server set up with the link above:

    {@snippet file = examples/application.yml lang = yaml}

    For a server elsewhere, change the address. Keep a real password out of the file, for example with password: ${TM1_PASSWORD} and an environment variable. {@link net.ajmyers.tm1.spring.boot.autoconfigure.Tm1Properties} lists every property.

  4. Say hello. The starter builds a Tm1Client from those settings; ask for it, and use it. This prints the server's version and lists its cubes when the application starts:

    {@snippet class = examples.HelloTm1Application region = hello-app}

    Run it with ./gradlew bootRun (or mvn spring-boot:run):

    Hello from TM1 11.8.03500.6
  Plan_BudgetPlan
  SalesCube
  ...

Where next

  • {@link net.ajmyers.tm1.spring.boot.autoconfigure.Tm1AutoConfiguration}: the beans it creates, and a session per user from the pool.
  • {@link net.ajmyers.tm1.spring.boot.autoconfigure.Tm1ConnectionDetails}: logging in your own way, such as with CAM.
  • tm1-spring-boot-testcontainers: a real TM1 in your Spring Boot tests.
