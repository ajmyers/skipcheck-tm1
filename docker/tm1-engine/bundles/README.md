# bundles/

Put IBM's TM1 v12 package here, e.g.

    tm1-v12.6.7-standalone-linux.tgz

Then run `docker compose up -d` from the folder above. It's installed once, on first
start. Use the **Linux** download, even on Mac or Windows.

Everything in this folder except this README is ignored by git, so your IBM software is
never committed.
